## Unreleased

### New

- The plan: research, architecture, data model, and roadmap.
- Course mode, in the Display menu. It hides the cloud account, version
  control, the AI assistant, board packages, Modbus, EtherCAT, OPC UA, and S7.
  It hides screens only: a project keeps its settings and builds the same way.
- Single stepping on the simulator and on Arduino boards. In a debug session,
  Pause holds the PLC between two scans, Step runs one scan, and Resume lets
  it run again. Build and upload the program again to use it on a board.
- The online view: during a debug session, the editor panel has a green
  border and an "Online" badge.
